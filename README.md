# Control de stock · Almacén

App web del almacén (CALIDAD, Stellantis): ingresos, egresos, stock de Comercial y del Taller, stock mínimo y rotación.
La copia de trabajo, las reglas de Firebase, las pruebas y el manual están en el repo de trabajo (`proyectos/control-stock-almacen/`).
Para actualizar la app, se reemplaza `index.html` por la versión nueva ya probada.
